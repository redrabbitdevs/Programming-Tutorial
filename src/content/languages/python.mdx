## Overview

Python is a high-level, general-purpose programming language built around readability. Significant indentation replaces braces, English keywords stand in for much of the punctuation other languages use, and the "batteries-included" standard library covers files, networking, testing, and more. Programs run on an interpreter with dynamic typing — optional static type annotations have been available since 3.5 — and garbage-collected memory.

## History & era

Guido van Rossum began Python in the late 1980s at CWI in the Netherlands as a successor to ABC, and first released it publicly on 20 February 1991 (version 0.9.0). Python 2.0 followed in 2000; Python 3.0 arrived in 2008 as a major, only partially backward-compatible revision, and Python 2 reached end-of-life in 2020. Development now runs through the Python Software Foundation's PEP process under an elected Steering Council. The current stable line is 3.15 (October 2026), with five minor versions supported at once.

## Paradigms

Python is multi-paradigm: object-oriented programming and procedural (imperative) code are first-class, and functional features — list comprehensions, generators, `map`/`filter`, and the `functools` and `itertools` modules — sit alongside them. Its duck-typed dynamic model is a defining trait: what an object *does* matters more than what it *is*.

## Ecosystem

The ecosystem is one of the language's great strengths. PyPI hosts over 900,000 packages; NumPy, Pandas, and scikit-learn anchor data science and machine learning; Django, Flask, and FastAPI cover web development; Jupyter drives interactive computing; MicroPython and CircuitPython bring Python to microcontrollers. In the TIOBE index for November 2026, Python holds the #1 position with a 20.86% rating.
