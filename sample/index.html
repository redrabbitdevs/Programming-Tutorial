Python Foundations Lesson 1 · ~8 min read

Variables: named boxes for your data

A variable is a name that refers to a value. When you write x = 5, Python creates the name x and points it at the number 5. You can reassign the name any time — the box keeps whatever value you last put in.

def greet(name):
    message = f"Hello, {name}!"  # f-string: text + values
    return message

print(greet("world"))   # → Hello, world!

TipName variables for what they hold — message, not m. Future you is a beginner again.

Try it yourself

Modify the function so it greets you. Change the name inside the greet(...) call, run it, and read the output. Then make it a little more personal.
