## Version verification

- Fetched `docs.python.org/3/reference/datamodel.html` on 2026-11-20 (Python **3.15.2** docs) to confirm: §3.3.9 context manager protocol — `__enter__`'s return value is bound to the `as` target; `__exit__(exc_type, exc_value, traceback)` receives all three as `None` on clean exit and returning a true value suppresses the exception; §3.2.8.3 generator functions — calling returns an iterator, `__next__` runs to the next `yield`, falling off the end raises StopIteration; plus `function.__annotations__` (keys = parameter names + `"return"`), `__name__`, `__doc__`.
