## Schema (enforced by `scripts/validate.mjs`)

Required per record: `name` (string), `aliases` (array), `paradigms` (array), `year` (number, first release/introduction), `status` ∈ `active|legacy|historical`, `helloWorld {lang: string, code: string}`, `pageStatus` ∈ `planned|written|published`.
Optional: `era` (string), `tiobeRank` (positive int), `trackSlug` (kebab-case; must have a matching `data/curriculum/<slug>.json` — only python has one today).

## Conventions (bind all batches)

- **Slug** = filename without `.json`, kebab-case of the canonical language name, unambiguous (`c`, `cpp`, `csharp`, `objective-c`, `visual-basic`). Dedupe across Wikipedia sub-lists + TIOBE.
- **era** = decade bucket derived from `year`: `"1950s"` … `"2020s"`. Alphabetical sort of these strings is chronological — keep to this exact set. **Normalize the existing `python.json` era `"modern"` → `"1990s"` in the first batch** (its only outlier value).
- **status**: `active` = maintained and in current use; `legacy` = no longer developed but still used or historically significant; `historical` = obsolete/archaeological.
- **paradigms**: lowercase kebab vocabulary, 1–4 per language (`object-oriented`, `procedural`, `functional`, `imperative`, `declarative`, `logic`, `assembly`, …). Keep the vocabulary tight and consistent across records so the index filter stays useful; when in doubt follow Wikipedia's classification for that language.
- **aliases**: common alternative names/identifiers (`python3`), not translations.
- **tiobeRank**: only for languages on the current TIOBE top-50 (Nov 2026 list); positive integer matching its index position.
- **helloWorld**: canonical minimal "Hello, World" in that language's syntax; `lang` = Shiki highlighter id where one exists, else lowercase name. These snippets are **not executed by CI** for planned records (no such job exists); correctness is sampled at the gate (below).
