# T-010 — /languages/ index page + slug routes

**Agent**: design-engineer · **Type**: design · **Branch**: `agent/design-engineer/languages-index` (from main baf794d)

## Scope (deliverables)

Wire the existing encyclopedia infrastructure to real data and ship the two planned routes (`src/pages/languages/index.astro`, `src/pages/languages/[slug].astro` — plan structure line 36–37):

1. **`src/pages/languages/index.astro`** — encyclopedia index:
   - At build time, read ALL `data/languages/*.json` records (glob) and map each to the existing `EncyclopediaTable` `LangRecord` shape: `{ name, slug (filename), paradigms, year, era, status, hasTrack }`.
   - `hasTrack`: derive from the record's `trackSlug` (present → true). Document the derivation in a comment.
   - Render page heading + short intro + `<EncyclopediaTable records={...} />` (component already implements client-side filter paradigm/era/status + sort name/year with aria-live count — do NOT re-implement or modify its behavior; it was built for exactly this in the design-system phase).
   - Must be fully data-driven: when T-009 lands the ~900+ roadmap records, this page must pick them up with zero code changes.
   - Follow existing page conventions (Base layout props for title/description, header nav pattern). Make the index discoverable from primary nav following the existing prop-driven `links` pattern in `src/components/Header.astro` (add "Languages" consistently; check how pages currently pass links and keep it uniform).
2. **`src/pages/languages/[slug].astro`** — single-language page:
   - `getStaticPaths` from `getCollection("languages", ({ data }) => data.pageStatus === "published")` (currently: python only) — same pattern as `src/pages/learn/[lang]/[...slug].astro`.
   - Render the MDX through the existing `Encyclopedia.astro` layout, passing its metadata props from frontmatter: `name, slug, status (frontmatter languageStatus), paradigms, year, era, tiobeRank, hasTrack`.
3. **e2e + axe** — extend coverage per plan CI line ("core set: home, a track hub, a lesson, encyclopedia index, a language page, dashboard"):
   - `tests/e2e/a11y.spec.ts`: add `/languages/` and `/languages/python/` to the audited route set (wcag2a/wcag2aa).
   - Core/feature spec: assert the index renders the table with the Python row + "Track" badge, filter/sort actually reorders rows client-side (e.g. select a paradigm filter → aria-live count updates), and `/languages/python/` renders h1 = language name + MDX body content.
4. **lychee** — do NOT remove the `.*/languages(/.*)?$` exclusion: after this PR only the `python` demo slug on the design-system page resolves; c/java/fortran/cobol/rust/scratch/abap still 404 (T-009/T-011 records + pages). Update its TODO comment to say so.
